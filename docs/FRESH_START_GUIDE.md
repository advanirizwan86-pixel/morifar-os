# Fresh Start Guide

1. Open `/admin/data-reset` as Super Admin.
2. Export the demo data JSON snapshot.
3. Type `RESET MORIFAR DEMO DATA`.
4. Run the reset.
5. Confirm users, roles, departments, Company Profile, AI Professionals and settings remain.
6. Open `/leads/new` and create the first real lead.
7. Qualify the lead in `/leads`.
8. Create or track the related client/company path in `/crm`.
9. Open `/company-formation` and create the first case when the operational workflow supports it.
10. Assign tasks in `/tasks/new`.
11. Request documents through the documents/company formation workflow.
12. Read AI recommendations, verify the explanation, and decide manually.
13. Use `/approvals` for sensitive milestones.
14. Track progress from Dashboard, Company Formation, Tasks and Notifications.
