# Daily Operating Playbook

## Morning Routine

- Check Dashboard.
- Check pending approvals.
- Check delayed tasks.
- Check new leads.
- Check AI recommendations.

## Lead Routine

- Add lead.
- Qualify lead.
- Convert lead to client operationally.
- Create case when ready.

## Company Formation Routine

- Create case.
- Collect documents.
- Assign consultant.
- Use AI checklist.
- Track timeline.
- Approve milestones.

## End-of-Day Routine

- Review open tasks.
- Review pending documents.
- Review overdue work.
- Review tomorrow priorities.
