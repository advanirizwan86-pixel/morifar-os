# API

Morifar OS currently uses Next.js server actions and one admin export route.

## Route Handlers

- `GET /admin/data-reset/export`: Super Admin-only JSON export of demo operational data before reset.

## Server Actions

- Lead creation and settings updates.
- Task creation/status changes.
- Workflow actions.
- Business operation updates.
- Company Profile save.
- Demo data reset.

## Future API Work

Formal REST/GraphQL endpoints, external integrations, webhooks, and SDKs are not part of Version 1.0 RC.
