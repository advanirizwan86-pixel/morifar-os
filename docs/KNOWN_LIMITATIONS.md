# Known Limitations

- SQLite on Vercel is ephemeral.
- File uploads are placeholder-level.
- External government, banking, email and payment integrations are not live.
- AI recommendations are deterministic/local until model orchestration is connected.
- No user-management UI yet.
- No full audit-grade backup/restore system beyond JSON demo export.
- Workflow execution is not yet backed by a durable workflow runtime.
