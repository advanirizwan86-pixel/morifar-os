# AI System

AI in Morifar OS is assistive, explainable and human-controlled.

## Principles

- AI assists but does not replace professionals.
- Every recommendation needs an explanation.
- Sensitive decisions require human approval.
- AI-generated content must be clearly labelled.
- Human accountability remains final.

## Current State

AI recommendations are deterministic/local and use existing platform data. Live model orchestration and external tool execution are future work.
