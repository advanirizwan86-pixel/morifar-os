# Project Overview

Morifar OS is an internal operating platform for Morifar Group. It supports daily work across sales, operations, formation, documents, approvals, AI support, workflow orchestration and executive intelligence.

## What It Does

- Captures and manages leads.
- Tracks clients, companies and operational tasks.
- Supports company formation case management.
- Tracks document requests and approvals.
- Shows AI recommendations with explanations.
- Provides workflow templates and run monitoring.
- Gives leadership operational intelligence.
- Provides CTO documentation, training and demo-data reset.

## Current Version

Version `1.0.0` Release Candidate.
