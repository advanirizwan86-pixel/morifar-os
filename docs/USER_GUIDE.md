# User Guide

## Daily Use

1. Open Dashboard.
2. Review pending tasks, approvals, new leads and renewals.
3. Open Leads to capture or qualify opportunities.
4. Use Tasks for daily work ownership.
5. Use Company Formation for active formation cases.
6. Use Documents to track requested and rejected documents.
7. Use Approvals for sensitive decisions.
8. Read AI recommendations as guidance, not final decisions.
9. Use Search for records.
10. Review Notifications before ending the day.
